[지도·API 관련 Q&A 목차]

이 폴더에는 직접 요청했던 지도와 API 기능만 정리했다.
발표, 코드 리뷰, 면담에서 물어볼 만한 질문과 답변 형식이다.

1. 01_지도와_GeoJSON_Q&A.txt
   - 카카오 지도 생성
   - GeoJSON과 행정동 경계
   - 좌표 순서와 도형 처리

2. 02_마커와_필터_Q&A.txt
   - 음식점 마커 생성과 초기화
   - 같은 좌표의 음식점 처리
   - 지역·카테고리·즐겨찾기 필터

3. 03_GPS와_주변맛집_Q&A.txt
   - 현재 위치 조회
   - 위치 권한과 오류 처리
   - 하버사인 거리 계산

4. 04_자동차_길찾기_Q&A.txt
   - 카카오모빌리티 REST API
   - 출발지·도착지와 query
   - JSON 경로 좌표와 Polyline

5. 05_API_로딩과_보안_Q&A.txt
   - JavaScript SDK 동적 로딩
   - REST API 호출
   - API 키와 Authorization
   - onload, onerror, callback

6. 06_지도코드_문법_Q&A.txt
   - await, Promise.all
   - response.ok
   - 화살표 함수, some, map
   - ||, ?., 삼항 연산자

7. 07_오류와_개선_Q&A.txt
   - 지도가 안 나오는 원인
   - 마커 중복과 API 오류
   - 현재 구조의 한계와 개선 방법

[답변 기준]

- 현재 프로젝트 코드의 동작을 기준으로 작성했다.
- 실제 API 키 값은 기록하지 않았다.
- 줄 번호는 코드 수정에 따라 달라질 수 있다.

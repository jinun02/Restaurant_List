[지도 코드 JavaScript 문법 Q&A]

Q1. `await`는 무슨 뜻인가요?

A. Promise 작업이 끝나 실제 결과가 돌아올 때까지 해당 async 함수의
다음 코드 실행을 기다린다는 뜻입니다.


Q2. await가 없으면 fetch 결과에는 무엇이 들어가나요?

A. 실제 Response가 아니라 아직 완료되지 않은 Promise가 들어갑니다.


Q3. await는 어디에서 사용할 수 있나요?

A. 일반적으로 `async`가 붙은 함수 안에서 사용합니다.

```javascript
async function loadData() {
    const response = await fetch(url);
}
```


Q4. `Promise.all()`은 무엇인가요?

A. 여러 비동기 작업을 동시에 시작하고 모두 끝날 때까지 기다립니다.
GeoJSON 두 파일을 동시에 불러올 때 사용했습니다.


Q5. `response.ok`는 무엇인가요?

A. HTTP 상태 코드가 200~299 범위인지 나타내는 Boolean 속성입니다.


Q6. `response => !response.ok`는 무슨 뜻인가요?

A. 현재 응답이 실패했는지 검사하는 화살표 함수입니다.

```javascript
function (response) {
    return !response.ok;
}
```

위 일반 함수와 같은 의미입니다.


Q7. `!`는 무엇인가요?

A. true와 false를 반대로 바꾸는 부정 연산자입니다.
따라서 `!response.ok`는 응답이 성공하지 않았다는 뜻입니다.


Q8. `some()`은 무엇인가요?

A. 배열 요소 중 하나라도 조건을 만족하면 true를 반환합니다.

```javascript
responses.some(response => !response.ok)
```

응답 중 하나라도 실패했는지를 검사합니다.


Q9. `map()`은 무엇인가요?

A. 배열의 각 요소를 변환해 새로운 배열을 만듭니다.

```javascript
responses.map(response => response.json())
```

각 Response를 JSON 변환 Promise로 바꿉니다.


Q10. `forEach()`은 무엇인가요?

A. 배열 요소마다 같은 작업을 실행합니다.
마커 제거, 경계 그리기, 경로 좌표 처리 등에 사용합니다.


Q11. `||`는 무엇인가요?

A. 왼쪽 값이 truthy면 왼쪽 값을, falsy면 오른쪽 값을 사용합니다.

```javascript
const restaurantData = window.restaurantData || {};
```

음식점 데이터가 없으면 빈 객체를 사용합니다.


Q12. 위 코드를 if문으로 바꾸면 어떻게 되나요?

A. 다음과 같습니다.

```javascript
let restaurantData;

if (window.restaurantData) {
    restaurantData = window.restaurantData;
} else {
    restaurantData = {};
}
```


Q13. `?.`는 무엇인가요?

A. 왼쪽 객체가 null이나 undefined가 아닐 때만 다음 속성 또는 함수를
사용하는 선택적 연결 연산자입니다.

```javascript
infoWindow?.close();
```


Q14. `routePolyline?.setMap(null)`은 무슨 뜻인가요?

A. 이전 경로선 객체가 존재할 때만 지도에서 제거한다는 뜻입니다.
첫 검색에서는 경로선이 없어도 오류가 발생하지 않습니다.


Q15. `visible ? map : null`은 무엇인가요?

A. 삼항 연산자입니다. visible이 true면 map을 사용하고,
false면 null을 사용합니다.


Q16. 구조 분해 할당은 무엇인가요?

A. 객체에서 필요한 속성을 바로 꺼내는 문법입니다.

```javascript
restaurantMarkers.forEach(({ marker }) => {
    marker.setMap(null);
});
```

각 배열 요소에서 marker 속성만 꺼냅니다.


Q17. 전개 문법 `...restaurant`는 무엇인가요?

A. 기존 음식점 객체의 모든 속성을 새 객체에 복사합니다.
그 뒤 거리 같은 새 속성을 추가할 수 있습니다.


Q18. `try`, `catch`, `finally`는 무엇인가요?

A. try는 실행할 코드, catch는 오류 처리,
finally는 성공과 실패에 관계없이 항상 실행할 코드입니다.


Q19. `throw new Error()`는 무엇인가요?

A. 현재 정상 실행을 중단하고 오류를 발생시킵니다.
상위 try/catch에서 오류 메시지를 받아 화면에 표시할 수 있습니다.


Q20. `const start = () => kakao.maps.load(initFoodMap);`은 무엇인가요?

A. start라는 변수에 화살표 함수를 저장한 것입니다.
start()를 호출하면 카카오 SDK 준비 후 initFoodMap을 실행합니다.

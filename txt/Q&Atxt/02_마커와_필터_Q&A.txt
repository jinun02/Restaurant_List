[음식점 마커와 필터 Q&A]

Q1. 음식점 위치는 지도에 어떻게 표시하나요?

A. CSV에서 읽은 위도와 경도로 `kakao.maps.Marker`를 생성합니다.
원본은 `js/restaurantMap.js` 203번째 줄 부근입니다.

```javascript
const marker = new kakao.maps.Marker({
    map,
    position: new kakao.maps.LatLng(
        restaurant.latitude,
        restaurant.longitude
    ),
    image: createMarkerImage(MARKER_SVG)
});
```


Q2. 카카오 지도에도 마커가 필요한가요?

A. 필요합니다. 지도 API는 기본 배경 지도만 제공합니다.
프로젝트의 음식점 위치는 자동으로 표시되지 않으므로 음식점마다
별도의 Marker를 만들어야 합니다.


Q3. 기존 마커를 먼저 제거하는 이유는 무엇인가요?

A. `createRestaurantMarkers()`가 다시 실행될 때 이전 마커가 남아 있으면
같은 위치에 새 마커가 계속 중복되기 때문입니다.

```javascript
restaurantMarkers.forEach(({ marker }) =>
    marker.setMap(null)
);
restaurantMarkers = [];
```

첫 코드는 지도 화면에서 제거하고, 두 번째 코드는 배열의 참조를 비웁니다.


Q4. 이 초기화는 카카오 지도 전체를 초기화하는 것인가요?

A. 아닙니다. 지도 객체와 행정동 경계는 유지하고 음식점 마커만
지도에서 제거한 뒤 새 데이터로 다시 생성합니다.


Q5. 같은 좌표의 음식점은 어떻게 처리하나요?

A. 위도와 경도를 문자열 키로 만들어 `Map` 객체에 묶습니다.
같은 건물에 음식점이 여러 개 있어도 마커는 하나만 만들고,
정보창에서 이전·다음 방식으로 여러 음식점을 확인할 수 있습니다.


Q6. 좌표에 `toFixed(8)`을 사용하는 이유는 무엇인가요?

A. 부동소수점 표현 차이로 사실상 같은 좌표가 다른 키로 분리되는 것을
줄이기 위해 소수점 8자리 문자열로 통일합니다.


Q7. 마커 이미지는 어떻게 만들었나요?

A. 식당 모양 SVG 문자열을 data URL로 바꾸고
`kakao.maps.MarkerImage` 객체로 변환했습니다.

```javascript
new kakao.maps.MarkerImage(
    `data:image/svg+xml;charset=UTF-8,${encodeURIComponent(svg)}`,
    new kakao.maps.Size(44, 48)
);
```


Q8. 마커 클릭 시 어떤 일이 발생하나요?

A. `kakao.maps.event.addListener()`가 클릭 이벤트를 등록합니다.
클릭하면 해당 좌표의 음식점 정보를 `InfoWindow`로 표시합니다.


Q9. 지역 필터는 어떻게 작동하나요?

A. 전체 지역이 선택됐거나 음식점의 `district`가 선택된 행정동 Set에
포함되어 있는지를 확인합니다.

```javascript
selectedDistricts.has(ALL) ||
selectedDistricts.has(restaurant.district)
```


Q10. 카테고리 필터는 어떻게 작동하나요?

A. 전체 카테고리거나 음식점의 `category`가 선택 값과 같은지 확인합니다.

```javascript
selectedCategory === ALL ||
restaurant.category === selectedCategory
```


Q11. 세 필터 조건을 `&&`로 연결한 이유는 무엇인가요?

A. 지역, 카테고리, 즐겨찾기 조건을 모두 통과한 음식점만 표시해야
하기 때문입니다. `&&`는 모든 조건이 true일 때만 true가 됩니다.


Q12. 마커는 어떻게 숨기거나 다시 표시하나요?

A. `marker.setMap(null)`이면 숨기고 `marker.setMap(map)`이면 표시합니다.

```javascript
marker.setMap(visible ? map : null);
```

마커 객체를 매번 새로 만들지 않고 지도 연결 상태만 바꿉니다.


Q13. `restaurants.some(matchesFilter)`는 무슨 뜻인가요?

A. 같은 위치에 묶인 음식점 중 하나라도 현재 필터 조건에 맞는지
검사합니다. 하나라도 맞으면 그 좌표의 마커를 표시합니다.


Q14. 즐겨찾기 데이터의 키를 변환하는 이유는 무엇인가요?

A. 즐겨찾기는 `행정동_카테고리_순번` 형식이고 지도 CSV 비교는
`행정동|음식점명` 형식을 사용합니다. 서로 다른 데이터 구조를
연결하기 위해 공통 키로 변환합니다.


Q15. `const restaurantData = window.restaurantData || {};`는 무슨 뜻인가요?

A. 전역 음식점 데이터가 있으면 사용하고, 없으면 빈 객체를 사용한다는
뜻입니다. 데이터가 아직 준비되지 않았을 때 `Object.entries(undefined)`
오류가 발생하는 것을 방지합니다.


Q16. 위 코드를 if문으로 바꿀 수 있나요?

A. 다음처럼 바꿀 수 있습니다.

```javascript
let restaurantData;

if (window.restaurantData) {
    restaurantData = window.restaurantData;
} else {
    restaurantData = {};
}
```


Q17. 즐겨찾기를 해제하면 지도도 바로 바뀌나요?

A. 즐겨찾기 전용 보기 상태라면 `syncFavoriteMarkers()`가 다시 실행되어
즐겨찾기 키 배열을 갱신하고 `updateMarkerVisibility()`가 마커를 다시
표시하거나 숨깁니다.

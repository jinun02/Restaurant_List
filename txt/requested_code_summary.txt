[지도 관련 코드 정리 문서 목차]

기존 문서가 너무 길어 기능별 파일로 나누었다.
아래 순서대로 읽으면 전체 동작을 이해하기 쉽다.

1. map_code/01_지도와_GeoJSON.txt
   - 카카오 지도 생성
   - GeoJSON 파일 로딩
   - response.ok
   - 화살표 함수와 some()
   - 행정동 경계 그리기

2. map_code/02_음식점_마커와_필터.txt
   - 음식점 마커 생성
   - 같은 위치의 음식점 묶기
   - 지역·카테고리 필터
   - 즐겨찾기 마커 연동

3. map_code/03_GPS와_주변맛집.txt
   - 현재 위치 조회
   - 위치 오류 처리
   - 하버사인 거리 계산
   - 선택 반경 내 음식점 검색

4. map_code/04_자동차_길찾기.txt
   - 카카오 길찾기 API 요청
   - JSON 응답 처리
   - 경로 좌표 변환
   - 지도에 경로선 표시

5. map_code/05_데이터와_미니지도.txt
   - 음식점 CSV 로딩
   - 상세 페이지 JSON 저장
   - 메인 페이지 미니 지도
   - 상세 페이지 미니 지도

6. map_code/06_자바스크립트_문법설명.txt
   - 화살표 함수
   - ! 부정 연산자
   - some(), map(), forEach()
   - async/await와 Promise.all()
   - ?.와 ?? 연산자

7. map_code/99_기존_전체정리_보관.txt
   - 분리 전 전체 문서 원본
   - 빠진 내용을 확인할 때만 참고

[줄 번호 안내]

각 문서의 줄 번호는 현재 프로젝트 소스 기준이다.
원본 코드가 수정되면 줄 번호도 달라질 수 있다.

[API 키 주의]

문서에는 실제 API 키를 기록하지 않았다.
API 키가 들어간 설정 파일은 공개 저장소에 커밋하지 않는 것이 좋다.

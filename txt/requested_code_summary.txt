[요청받아 제작·수정한 코드 정리]

작성 기준
- Git 커밋 기록에서 지도, 위치, 음식점 데이터, 즐겨찾기와 관련해 제작·수정된 내용을 중심으로 정리했다.
- 프로젝트 전체 코드를 복사한 문서가 아니라, 각 기능의 역할과 핵심 코드 흐름을 확인할 수 있도록 요약했다.
- API 인증키는 보안을 위해 기록하지 않았다. 실제 키는 저장소에 커밋하지 않는 것이 좋다.

============================================================
1. 전체 작업 요약
============================================================

요청받아 제작하거나 수정한 부분은 대부분 지도 기능이다.

1) 음식점 CSV 데이터를 지도 마커로 표시
2) 행정동 및 음식 카테고리별 지도 필터링
3) 지도 마커와 좌측 음식점 목록 연동
4) 즐겨찾기한 음식점만 목록과 지도에 표시
5) 브라우저 GPS를 이용한 현재 위치 표시
6) 현재 위치 기준 주변 맛집 검색 및 거리 계산
7) 출발지·도착지 지정과 자동차 길찾기
8) 메인 페이지 및 상세 페이지의 미니 지도
9) 같은 좌표의 음식점 묶음 표시와 정보창 처리
10) 지도 UI, 확대·축소 버튼, 현재 위치 버튼 및 길찾기 패널

3. 맛집 탐색 지도 핵심 코드
============================================================

대상 파일: js/restaurantMap.js

[3-1. 지도 생성]

카카오 지도의 중심을 춘천으로 설정하고 기본 확대 수준을 지정한다.

    map = new kakao.maps.Map(mapElement, {
        center: new kakao.maps.LatLng(37.8813, 127.7298),
        level: 7
    });

[3-2. 선택 조건에 맞는 음식점 판별]

행정동, 음식 카테고리, 즐겨찾기 여부를 모두 검사해 마커 표시 여부를 결정한다.

    const getRestaurantKey = restaurant =>
        `${restaurant.district}|${restaurant.name}`;

    const matchesFilter = restaurant =>
        (selectedDistricts.has(ALL) ||
            selectedDistricts.has(restaurant.district)) &&
        (selectedCategory === ALL ||
            restaurant.category === selectedCategory) &&
        (favoriteRestaurantKeys === null ||
            favoriteRestaurantKeys.has(getRestaurantKey(restaurant)));

[3-3. 마커 표시 상태 갱신]

한 좌표에 여러 음식점이 묶여 있을 수 있으므로, 묶음 중 하나라도 조건에 맞으면 해당 마커를 표시한다.

    function updateMarkerVisibility() {
        if (!map) return;

        restaurantMarkers.forEach(({ restaurants, marker }) =>
            marker.setMap(restaurants.some(matchesFilter) ? map : null)
        );
    }

[3-4. 음식점 마커 생성]

음식점 좌표별로 마커를 만들고 클릭 시 음식점 정보창을 연다.

    const marker = new kakao.maps.Marker({
        map,
        position: new kakao.maps.LatLng(
            restaurant.latitude,
            restaurant.longitude
        ),
        title: restaurant.name,
        image: createMarkerImage(MARKER_SVG)
    });

    kakao.maps.event.addListener(marker, 'click', () =>
        openRestaurantGroup(marker, restaurantsAtPosition)
    );

[3-5. 외부 기능에 제공하는 지도 API]

RestaurantExplorer와 DirectionsController가 지도 기능을 호출할 수 있도록 전역 객체로 공개한다.

    window.RestaurantMap = {
        load: loadKakaoMaps,
        highlightDistricts,
        selectCategory(category) {
            selectedCategory = category;
            updateMarkerVisibility();
        },
        selectFavorites(keys) {
            favoriteRestaurantKeys =
                keys === null ? null : new Set(keys);
            updateMarkerVisibility();
        },
        setRestaurants: createRestaurantMarkers,
        resize() { map?.relayout(); },
        getMap: () => map,
        createMarkerImage
    };

4. 음식점 목록과 지도 필터 연동
============================================================

대상 파일: js/restaurantExplorer.js

[4-1. 즐겨찾기 키 변환]

로그인 즐겨찾기는 "행정동_카테고리_순번" 형식을 사용하지만 지도 CSV는 음식점 정보를 기준으로 비교한다. 따라서 즐겨찾기 항목을 "행정동|음식점명" 형식으로 변환한다.

    function getFavoriteRestaurantKeys() {
        const keys = [];
        const restaurantData = window.restaurantData || {};

        Object.entries(restaurantData).forEach(([district, districtData]) => {
            Object.entries(districtData).forEach(([category, stores]) => {
                stores.forEach((store, index) => {
                    if (isFavorite(`${district}_${category}_${index}`)) {
                        keys.push(`${district}|${store.name}`);
                    }
                });
            });
        });

        return keys;
    }

[4-2. 즐겨찾기 마커 동기화]

즐겨찾기 전용 보기가 켜져 있으면 즐겨찾기 키만 지도에 전달하고, 꺼져 있으면 null을 전달해 모든 마커를 다시 표시한다.

    function syncFavoriteMarkers() {
        window.RestaurantMap?.selectFavorites(
            favoritesOnly ? getFavoriteRestaurantKeys() : null
        );
    }

[4-3. 행정동과 카테고리 연동]

    window.RestaurantMap?.highlightDistricts(
        Array.from(selectedDistricts)
    );

    window.RestaurantMap?.selectCategory(category);

[4-4. 음식점 카드 기능]

- 카드 클릭: 음식점 상세 페이지로 이동
- 별 버튼: 즐겨찾기 추가 또는 해제
- 길찾기 버튼: 선택한 음식점을 도착지로 지정
- 즐겨찾기 보기 상태에서 별을 해제하면 목록과 마커를 즉시 다시 그림

5. 현재 위치 기능
============================================================

대상 파일: js/geolocationService.js

[5-1. 현재 위치 한 번 조회]

    navigator.geolocation.getCurrentPosition(
        position => resolve({
            latitude: position.coords.latitude,
            longitude: position.coords.longitude,
            accuracy: position.coords.accuracy
        }),
        error => reject(new Error(getErrorMessage(error))),
        options
    );

[5-2. 위치 추적]

watchPosition으로 위치 변경을 계속 받아 지도 마커를 갱신하며, 더 이상 필요하지 않을 때 clearWatch로 추적을 중지한다.

    watchId = navigator.geolocation.watchPosition(
        position => onPosition(normalizePosition(position)),
        error => onError?.(new Error(getErrorMessage(error))),
        options
    );

주요 예외 처리
- 브라우저가 위치 기능을 지원하지 않는 경우
- 사용자가 위치 권한을 거부한 경우
- 현재 위치를 확인할 수 없는 경우
- 위치 조회 시간이 초과된 경우

6. 내 주변 맛집 검색
============================================================

대상 파일: js/nearbyRestaurantService.js

두 좌표 사이의 거리는 하버사인 공식을 이용해 계산한다.

    function calculateDistanceKm(origin, destination) {
        const start = normalizeLocation(origin);
        const end = normalizeLocation(destination);
        const latitudeDifference = toRadians(
            end.latitude - start.latitude
        );
        const longitudeDifference = toRadians(
            end.longitude - start.longitude
        );

        const haversine =
            Math.sin(latitudeDifference / 2) ** 2 +
            Math.cos(toRadians(start.latitude)) *
            Math.cos(toRadians(end.latitude)) *
            Math.sin(longitudeDifference / 2) ** 2;

        return EARTH_RADIUS_KM * 2 * Math.atan2(
            Math.sqrt(haversine),
            Math.sqrt(1 - haversine)
        );
    }

계산한 거리가 사용자가 선택한 반경 이내인 음식점만 남기고 거리순 또는 평점순으로 정렬한다. 메인 화면에서는 0.5km 등의 기본 반경과 사용자 지정 반경을 지원한다.

7. 자동차 길찾기
============================================================

대상 파일: js/directionsService.js, js/directionsController.js

[7-1. 경로 API 요청]

DirectionsService는 출발지와 도착지 좌표로 카카오 길찾기 REST API를 호출한다.

    const response = await fetch(url, {
        headers: {
            Authorization: `KakaoAK ${apiKey}`
        }
    });

주의: API 키 문자열은 이 문서에 기록하지 않았다.

[7-2. 응답 데이터 변환]

API 응답의 도로 구간 좌표를 지도에서 사용할 위도·경도 배열로 변환하고 전체 거리와 예상 시간을 반환한다.

    return {
        points,
        distance: route.summary.distance,
        duration: route.summary.duration
    };

[7-3. 지도에 경로 그리기]

    const path = route.points.map(point =>
        new kakao.maps.LatLng(point.latitude, point.longitude)
    );

    routePolyline = new kakao.maps.Polyline({
        map,
        path,
        strokeWeight: 6,
        strokeColor: '#2563eb',
        strokeOpacity: 0.9,
        strokeStyle: 'solid'

[7-4. 길찾기 UI 흐름]

1) 지도 우클릭 또는 음식점 카드의 길찾기 버튼으로 위치 선택
2) 출발지와 도착지 마커 표시
3) 두 위치가 모두 설정되었는지 검사
4) 자동차 경로 API 요청
5) 경로 선을 지도에 표시
6) 거리와 예상 시간을 결과 패널에 출력

12. 작업 흐름 요약
============================================================

음식점 CSV
    -> RestaurantService가 데이터 변환
    -> RestaurantMap이 좌표별 마커 생성
    -> RestaurantExplorer가 지역·카테고리·즐겨찾기 조건 전달

    -> GeolocationService가 좌표 조회
    -> RestaurantMap 또는 HomepageMap에 현재 위치 표시
    -> NearbyRestaurantService가 음식점까지 거리 계산
    -> 선택 반경 안의 주변 맛집 표시

출발지·도착지
    -> DirectionsController가 위치 관리
    -> DirectionsService가 자동차 경로 요청
    -> 지도에 경로선, 거리, 예상 시간 표시

14. API 키 관리 주의사항
============================================================

현재 프로젝트에는 다음 지도 설정 파일이 있다.

- js/map-config.js
- js/map-config-KakaoJS.js
- js/map-config-KakaoRest.js

이 파일에 실제 API 키를 작성하면 브라우저에서 노출될 수 있다. JavaScript 지도 키는 서비스 도메인 제한을 반드시 설정하고, REST API 키가 보호되어야 한다면 별도 서버에서 요청을 중계하는 구조를 사용하는 것이 안전하다. 실제 API 키가 들어간 설정 파일은 공개 Git 저장소에 커밋하지 않는 것이 좋다.


[정리 결론]

부탁받아 제작·수정한 코드의 중심은 지도 기능이며, 단순히 지도를 띄우는 수준이 아니라 음식점 데이터, 목록 필터, 즐겨찾기, GPS, 주변 검색, 길찾기, 메인·상세 미니 지도까지 연결한 구조다.

아래 코드는 프로젝트의 핵심 동작을 이해하기 쉽도록 일부 코드를 뽑아 주석을 추가한 것이다. 원본 파일의 모든 코드를 그대로 복사한 것이 아니라, 기능별 실행 흐름이 드러나는 부분을 정리했다.

사용 파일

    // 행정동 경계가 들어 있는 GeoJSON 파일 경로
    const DISTRICT_URL =
        '../data/area/chuncheon-admin-dong.geojson';

    // 춘천시 전체 외곽선이 들어 있는 GeoJSON 파일 경로
    const CITY_URL =
        '../data/area/chuncheon-city-boundary.geojson';

    async function loadBoundaries() {
        // 두 파일은 서로 독립적이므로 동시에 요청한다.
        // 순서대로 기다리는 것보다 로딩 시간을 줄일 수 있다.
        const responses = await Promise.all([
            fetch(DISTRICT_URL),
            fetch(CITY_URL)
        ]);

        // 하나라도 HTTP 요청에 실패하면 지도 경계를 그릴 수 없으므로
        // 오류를 발생시켜 지도 로딩 화면에 안내한다.
        if (responses.some(response => !response.ok)) {
            throw new Error(
                '춘천시 경계 파일을 불러오지 못했습니다.'
            );
        }

        // 응답 본문을 JSON 객체로 변환한다.
        // 첫 번째 결과는 행정동, 두 번째 결과는 춘천시 외곽선이다.
        [districtGeoJson, cityGeoJson] = await Promise.all(
            responses.map(response => response.json())
        );

        // 경계 데이터 준비가 완료됐음을 기록한다.
        boundaryLoaded = true;

        // 현재 선택된 지역을 기준으로 경계선을 실제 지도에 그린다.
        highlightDistricts(Array.from(selectedDistricts));
    }

활용 방식
1) food_page.html이 열리면 restaurantMap.js가 실행된다.
2) 두 GeoJSON 파일을 fetch로 읽는다.
3) JSON 객체의 features 배열에서 행정동 이름과 좌표를 꺼낸다.
4) 좌표를 카카오 지도 Polygon 또는 Polyline으로 변환한다.
5) 사용자가 선택한 행정동 영역을 지도에 강조한다.

15-2. GeoJSON 좌표를 카카오 지도 좌표로 변환
------------------------------------------------------------

GeoJSON은 좌표를 [경도, 위도] 순서로 저장하지만 카카오 지도는 LatLng(위도, 경도) 순서로 받는다. 순서를 반드시 바꿔야 한다.

    // coordinate[0] = 경도(longitude)
    // coordinate[1] = 위도(latitude)
    const latLng = coordinate =>
        new kakao.maps.LatLng(
            coordinate[1], // 위도
            coordinate[0]  // 경도
        );

    // Polygon과 MultiPolygon은 좌표 배열의 중첩 깊이가 다르다.
    // 이후 코드를 공통으로 사용하기 위해 Polygon도 배열로 감싼다.
    const polygonsOf = geometry =>
        geometry.type === 'Polygon'
            ? [geometry.coordinates]
            : geometry.coordinates;

활용 위치
- 행정동 면 영역 그리기
- 춘천시 전체 외곽선 그리기
- 선택된 지역에 맞춰 지도 화면 범위 이동

15-3. 행정동 경계선과 면 영역 그리기
------------------------------------------------------------

    function drawBoundaries() {
        // 이전에 그려진 경계를 먼저 제거한다.
        // 제거하지 않으면 사용자가 지역을 바꿀 때 도형이 계속 겹친다.
        clearOverlays(boundaryOverlays);

        // '전체' 선택 여부를 확인한다.
        const showAll = selectedDistricts.has(ALL);

        // 전체 보기면 춘천시 외곽선을 사용하고,
        // 특정 동 보기면 행정동별 경계 데이터를 사용한다.
        const features = showAll
            ? cityGeoJson.features
            : districtGeoJson.features;

        features.forEach(feature => {
            // GeoJSON properties의 ADM_NM에 행정동 이름이 들어 있다.
            const selected = showAll || selectedDistricts.has(
                feature.properties?.ADM_NM
            );

            if (feature.geometry.type === 'MultiLineString') {
                // 춘천시 전체 경계는 선 데이터이므로 Polyline 사용
                feature.geometry.coordinates.forEach(line => {
                    const overlay = new kakao.maps.Polyline({
                        map,
                        // 모든 GeoJSON 좌표의 위도·경도 순서를 변환
                        path: line.map(latLng),
                        strokeWeight: 4,
                        strokeColor: '#ba0707',
                        strokeOpacity: 1
                    });

                    // 나중에 제거할 수 있도록 배열에 저장한다.
                    boundaryOverlays.push(overlay);
                });
                return;
            }

            // 행정동 경계는 면 데이터이므로 Polygon 사용
            polygonsOf(feature.geometry).forEach(polygon => {
                const overlay = new kakao.maps.Polygon({
                    map,
                    // 바깥쪽 테두리와 내부 구멍의 좌표를 모두 변환
                    path: polygon.map(ring => ring.map(latLng)),
                    strokeColor: '#64748b',
                    fillColor: '#fff',
                    // 선택된 동은 면 색을 더 진하게 표시
                    fillOpacity: selected ? 0.28 : 0.02
                });

                boundaryOverlays.push(overlay);
            });
        });
    }

화면에서의 결과
- '전체' 선택: 춘천시 외곽 경계 표시
- 특정 행정동 선택: 해당 동의 면 영역 강조
- 여러 행정동 선택: 선택 지역들의 바깥 윤곽을 강조

    function createRestaurantMarkers(restaurants) {
        // 기존 마커를 지도에서 제거한다.
        restaurantMarkers.forEach(({ marker }) =>
            marker.setMap(null)
        );
        restaurantMarkers = [];

        // 같은 위도와 경도를 가진 음식점들을 한 그룹으로 묶는다.
        // 동일한 건물에 여러 음식점이 있을 때 마커가 완전히 겹치는 문제를 해결한다.
        const groups = new Map();

        restaurants.forEach(restaurant => {
            // 소수점 오차 때문에 같은 좌표가 다르게 분류되지 않도록
            // 위도와 경도를 소수점 8자리 문자열로 통일한다.
            const key =
                `${restaurant.latitude.toFixed(8)},` +
                `${restaurant.longitude.toFixed(8)}`;

            const group = groups.get(key) || [];
            group.push(restaurant);
            groups.set(key, group);
        });

        groups.forEach(restaurantsAtPosition => {
            // 그룹의 첫 번째 음식점 좌표를 대표 좌표로 사용한다.
            const restaurant = restaurantsAtPosition[0];

            const marker = new kakao.maps.Marker({
                // 그룹 안에 현재 필터와 일치하는 음식점이 있을 때만 표시
                map: restaurantsAtPosition.some(matchesFilter)
                    ? map
                    : null,
                position: new kakao.maps.LatLng(
                    restaurant.latitude,
                    restaurant.longitude
                ),
                title: restaurant.name,

                // 문자열로 만든 식당 모양 SVG를 마커 이미지로 변환한다.
                image: createMarkerImage(MARKER_SVG)
            });

            // 마커를 클릭하면 같은 위치의 음식점 정보를 보여준다.
            kakao.maps.event.addListener(marker, 'click', () =>
                openRestaurantGroup(
                    marker,
                    restaurantsAtPosition
                )
            );

            // 필터 변경 시 다시 사용할 음식점 데이터와 마커를 저장한다.
            restaurantMarkers.push({
                restaurants: restaurantsAtPosition,
                marker
            });
        });

    }

    }

    function getCurrentPosition(options = {}) {
        // 브라우저가 Geolocation API를 제공하는지 검사
        if (!navigator.geolocation) {
            return Promise.reject(new Error(
                '이 브라우저는 현재 위치 기능을 지원하지 않습니다.'
            ));
        }

        // 콜백 방식의 브라우저 API를 Promise로 감싸
        // 다른 코드에서 await로 쉽게 사용할 수 있게 한다.
        return new Promise((resolve, reject) => {
            navigator.geolocation.getCurrentPosition(
                position => resolve({
                    latitude: position.coords.latitude,
                    longitude: position.coords.longitude,
                    accuracy: position.coords.accuracy
                }),
                error => reject(
                    new Error(getErrorMessage(error))
                ),
                { ...DEFAULT_OPTIONS, ...options }
            );
        });
    }

15-9. 현재 위치에서 음식점까지 거리 계산
------------------------------------------------------------

사용 파일: js/nearbyRestaurantService.js

    function calculateDistanceKm(origin, destination) {
        // lat/lng 또는 latitude/longitude 형식을 하나로 통일하고 검증
        const start = normalizeLocation(origin);
        const end = normalizeLocation(destination);

        // 삼각함수 계산을 위해 각도 단위를 도에서 라디안으로 변환
        const latitudeDifference = toRadians(
            end.latitude - start.latitude
        );
        const longitudeDifference = toRadians(
            end.longitude - start.longitude
        );

        // 지구 곡면에서 두 좌표 사이의 대권거리를 구하는
        // Haversine 공식의 핵심 계산
        const haversine =
            Math.sin(latitudeDifference / 2) ** 2 +
            Math.cos(toRadians(start.latitude)) *
            Math.cos(toRadians(end.latitude)) *
            Math.sin(longitudeDifference / 2) ** 2;

        // 지구 평균 반지름을 곱해 km 단위 거리로 반환
        return EARTH_RADIUS_KM * 2 * Math.atan2(
            Math.sqrt(haversine),
            Math.sqrt(1 - haversine)
        );
    }

    function findNearby({
        origin,
        restaurants = [],
        radiusKm = 3,
        limit = Infinity,
        sortBy = 'distance'
    } = {}) {
        return restaurants
            // 좌표가 잘못된 음식점은 제외하고 거리 정보 추가
            .flatMap(restaurant => {
                try {
                    const distanceKm = calculateDistanceKm(
                        origin,
                        restaurant
                    );

                    // 사용자가 선택한 반경 밖이면 결과에서 제외
                    if (distanceKm > radiusKm) return [];

                    return [{
                        ...restaurant,
                        distanceKm,
                        distanceLabel: formatDistance(distanceKm)
                    }];
                } catch (error) {
                    return [];
                }
            })
            // 거리순 또는 평점순 정렬
            .sort(sortBy === 'rating'
                ? ratingSort
                : distanceSort)
            // 화면에 필요한 개수만 반환
            .slice(0, limit);
    }

주의
- 이 값은 도로를 따라가는 실제 이동 거리가 아니라 두 좌표의 직선거리다.
- 실제 자동차 이동 거리는 길찾기 API 결과를 사용한다.

15-10. 카카오 자동차 길찾기 요청

사용 파일: js/directionsService.js

    async function findDrivingRoute(origin, destination) {
        // 카카오 API가 요구하는 "경도,위도" 문자열을 만든다.
        const query = new URLSearchParams({
            origin:
                `${origin.longitude},${origin.latitude}`,
            destination:
                `${destination.longitude},${destination.latitude}`,
            priority: 'RECOMMEND', // 추천 경로 요청
            alternatives: 'false', // 대안 경로는 요청하지 않음
            road_details: 'false'  // 상세 도로 정보 생략
        });

        const response = await fetch(
            `${DIRECTIONS_ENDPOINT}?${query}`,
            {
                headers: {
                    // 실제 키 값은 map-config-KakaoRest.js에서 읽는다.
                    Authorization: `KakaoAK ${getApiKey()}`
                }
            }
        );

        // 인증 실패와 일반 요청 실패를 구분해 사용자에게 안내한다.
        if (!response.ok) {
            if (response.status === 401 ||
                response.status === 403) {
                throw new Error(
                    '길찾기 API 인증에 실패했습니다.'
                );
            }
            throw new Error(
                `길찾기 요청에 실패했습니다. (${response.status})`
            );
        }

        // 서버가 반환한 JSON 문자열을 JavaScript 객체로 변환
        const data = await response.json();

        // 첫 번째 추천 경로를 사용한다.
        const route = data.routes?.[0];

        const points = [];

        // vertexes는 [경도, 위도, 경도, 위도, ...] 형태이므로
        // 두 개씩 읽어 지도에서 사용할 좌표 객체로 변환한다.
        route.sections?.forEach(section => {
            section.roads?.forEach(road => {
                for (
                    let index = 0;
                    index < road.vertexes.length;
                    index += 2
                ) {
                    points.push({
                        longitude: road.vertexes[index],
                        latitude: road.vertexes[index + 1]
                    });
                }
            });
        });

        return {
            // 지도에 선을 그릴 좌표 배열
            points,

            // API가 계산한 실제 도로 이동 거리(미터)
            distance: route.summary.distance,

            // API가 계산한 예상 이동 시간(초)
            duration: route.summary.duration
        };
    }

    function drawRoute(route) {
        // 맛집 탐색에서 사용 중인 카카오 지도 객체를 가져온다.
        const map = window.RestaurantMap?.getMap();
        if (!map) return;

        // 이전 검색에서 그린 경로가 있으면 제거한다.
        routePolyline?.setMap(null);

        // DirectionsService의 좌표 객체를 카카오 LatLng로 변환한다.
        const path = route.points.map(point =>
            new kakao.maps.LatLng(
                point.latitude,
                point.longitude
            )
        );

        // 변환된 좌표들을 이어 자동차 경로선을 그린다.
        routePolyline = new kakao.maps.Polyline({
            map,
            path,
            strokeWeight: 7,
            strokeColor: '#eb1111',
            strokeOpacity: 0.9,
            strokeStyle: 'solid'
        });

        // 경로 전체가 화면에 들어오도록 지도 범위를 조절한다.
        const bounds = new kakao.maps.LatLngBounds();
        path.forEach(position => bounds.extend(position));
        map.setBounds(bounds, 72, 72, 72, 72);
    }

    async function findRoute() {
        // 출발지나 도착지가 비어 있으면 API를 호출하지 않는다.
        if (!routeLocations.origin ||
            !routeLocations.destination) {
            showRouteResult(
                '출발지와 도착지를 모두 선택해 주세요.',
                true
            );
            return;
        }

        const route = await window.DirectionsService
            .findDrivingRoute(
                routeLocations.origin,
                routeLocations.destination
            );

        // 반환받은 좌표로 지도에 경로 표시
        drawRoute(route);

        // 미터와 초 단위를 읽기 쉬운 km와 분 단위로 바꿔 표시
        showRouteResult(
            `자동차 · ${formatDistance(route.distance)}` +
            ` · 약 ${formatDuration(route.duration)}`
        );
    }

16. JSON과 GeoJSON이 사용된 부분 요약
============================================================

1) 직접 저장된 JSON 계열 파일
- chuncheon-admin-dong.geojson: 춘천시 행정동별 면 좌표
- chuncheon-city-boundary.geojson: 춘천시 전체 외곽선 좌표

2) 서버 응답 JSON
- 카카오 길찾기 API 응답을 response.json()으로 변환
- 응답의 routes, sections, roads, vertexes를 이용해 경로 생성

3) 브라우저 저장용 JSON
- 선택한 음식점 정보를 JSON.stringify()로 sessionStorage에 저장
- 상세 페이지에서 JSON.parse()로 다시 읽어 미니 지도에 활용

4) 음식점 원본 데이터
- 음식점 목록과 좌표 원본은 JSON 파일이 아니라 주로 CSV를 사용
- restaurantService.js가 CSV 문자열을 JavaScript 객체 배열로 변환

따라서 지도에서 JSON이 가장 직접적으로 사용된 부분은 행정구역 경계 GeoJSON과 길찾기 API 응답 처리다.
